# Dictionary Web App

##  About Project 

This is the Dictionary web app use to search words according to user's need.It have simple UI user can easily search any word and in the result he/she will get The Meaning,Example,Synonyms, Read more option through which user can go to wekipedia for extra deep knowledge about that word.This is possible because of API which I am using in this Project it fetch the data from that show us the result.


---

### Language Used
- **HTML** – for structure
- **CSS** – Styling, layout, colors.
- **JavaScript** – for functionality

### How It Works
1. You have to Enter word which you want.
2. Then You have to click on search button.
3. After that you will get the result.
